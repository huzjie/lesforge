# 规格：前瞻专家调度（LES）

## 目标

在专家权重部分驻留 RAM、其余驻留 SSD 的约束下，把 SSD 读延迟与计算重叠，
最大化有效吞吐（吞吐 = 计算时间 / 总墙钟）。

## 输入

- 每层真实路由（mock 下由确定性模型给出）。
- 前瞻预测器（能力 skill）。
- 常驻上限 `resident_experts`、预取深度 `prefetch_depth`。

## 输出

- `hit_rate`：前瞻预取覆盖的所需专家占比。
- `stalls`：专家未常驻导致的 SSD 阻塞次数。
- `speedup`：串行墙钟 / 重叠墙钟。

## 不变量

- 冷启动（层 0）不计入命中率。
- skill=0.5 时预测纯随机（命中率 ≈ top_k/n_experts）。
- skill=1.0 时预测恒定命中（命中率 = 1.0）。
